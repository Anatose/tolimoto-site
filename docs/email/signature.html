Как поставить в Gmail

  1. Gmail → шестерёнка → Все настройки → вкладка Общие → раздел Подпись → Создать, назовите «Tolimoto».
  2. Вставьте скопированную подпись в поле (Cmd+V).
  3. Ниже, в «Настройки подписи по умолчанию», выберите адрес contact@tolimoto.com и подпись «Tolimoto» для новых писем и для ответов.
  4. Внизу страницы нажмите Сохранить изменения.
